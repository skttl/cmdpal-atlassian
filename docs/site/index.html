Links for Atlassian

Find your repository, project or Confluence page. Choose a destination. Open it in your browser.

  • bb dans searches Bitbucket repositories, with links to source, pull requests, branches and pipelines.
  • ji dans searches Jira projects, with links to issues, boards and supported backlogs.
  • cf dans searches Confluence spaces and page titles.
